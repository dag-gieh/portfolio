# Doughlas Nyarango Bosire — Biomedical Engineering Portfolio

An animated, responsive portfolio for biomedical engineer and healthcare technology consultant Doughlas Nyarango Bosire. It highlights substantiated project case studies, clinical engineering skills, medical-device compliance, healthcare infrastructure, career history, education, and contact details. The visual design uses the supplied white, light grey, orange-gold, navy and black palette, with original CSS engineering diagrams rather than copied or unapproved facility imagery.

## Start locally

1. Install Node.js (18 or newer).
2. In Windows PowerShell, run `npm.cmd install` in this project folder.
3. Run `npm.cmd run dev` and open the local URL printed by Vite.
4. Run `npm.cmd run build` to create a production build.

PowerShell may block the `npm.ps1` script due to its execution policy. Using the Windows command shim (`npm.cmd`) avoids changing that security setting. In Command Prompt or other terminals, the usual `npm` commands work.

## Portfolio content and publishing notes

The `portfolio` object near the top of `src/App.tsx` contains the profile, project case studies, employment and education history, expertise, metrics, leadership, and contact information used by the page. Add an approved portrait to replace the labeled initials placeholder. CV links currently open an email request because a downloadable CV file was not supplied. Add project photographs, engineering drawings, standards, tools, or redacted documentation only after confirming the details and permission to share them.

Regulatory practice is distinguished from ongoing MDSW study and ISO 13485 certification. Review dates, spellings, figures, facility names, and any details you would prefer not to publish before sharing the site publicly.

The capability groups are organized using lifecycle distinctions reflected in the linked World Health Organization guides on medical-equipment inventory, maintenance, and medical-device regulation. Those references inform the presentation only; the listed skills come from the supplied resume and do not imply WHO endorsement.
